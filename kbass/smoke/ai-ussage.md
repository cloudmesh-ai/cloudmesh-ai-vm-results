# AI Usage Disclosure

## AI Tool

ChatGPT (OpenAI) was used as a development assistant for this project.

## How AI Was Used

AI assistance included:

- Planning the smoke-test analysis workflow.
- Developing and refining Python code for JSON and CSV ingestion.
- Creating execution-time visualizations using pandas and Matplotlib.
- Implementing automated Markdown report generation.
- Preparing the Makefile and dependency documentation.
- Suggesting validation procedures and interpreting test output.
- Improving documentation structure and readability.

## Human Contribution and Verification

The contributor executed the commands, inspected terminal output,
tested the implementation, and reviewed the generated results.

The benchmark measurements were obtained from existing contributor
results in the repository, including the contributor's own Lima
smoke-test measurements.

AI did not generate or fabricate benchmark measurements.

## Limitations

AI-generated code and explanations require independent verification.
The analysis is descriptive, and performance comparisons may be
affected by differences in hardware, software, configurations,
and benchmark workloads.
